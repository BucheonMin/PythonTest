# Python Tetris

파이게임으로 만든 간단한 테트리스 게임입니다.

## 게임 설명
- 화살표 키로 블록을 조작할 수 있습니다.
- ↑ : 블록 회전
- ← → : 블록 좌우 이동
- ↓ : 블록 하강

## 설치 방법
```bash
pip install -r requirements.txt
```

## 실행 방법
```bash
python tetris.py
```

## 게임 규칙
- 블록을 회전하고 이동하여 가로줄을 완성하세요.
- 가로줄이 완성되면 해당 줄이 사라지고 점수를 얻습니다.
- 블록이 화면 상단에 닿으면 게임이 종료됩니다.
